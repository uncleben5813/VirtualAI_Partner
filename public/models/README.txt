PUT YOUR MAYA VRM MODEL HERE

Filename required:
public/models/maya.vrm

The model should be a VRM 1.0 avatar with facial expressions/blendshapes for:
- blink
- happy / sad / angry / surprised / relaxed / neutral
- aa / ih / ou / ee / oh mouth expressions
- eye look-at support

If maya.vrm is missing, the app automatically shows the existing Maya JPG fallback.
